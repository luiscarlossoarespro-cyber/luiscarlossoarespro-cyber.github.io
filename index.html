Boas práticas de engenharia de dados que aplico

  • Código versionado no GitHub, em etapas numeradas
  • Um comando refaz o projeto inteiro do zero
  • Auditoria de qualidade antes de qualquer número
  • Números do relatório conferidos por script
  • Validação temporal no modelo (sem "vazar" o futuro)
  • Documentação: relatório técnico e dicionário de dados
